### Simple Movie Recommender

A minimal movie recommender that uses hand-crafted genre vectors and cosine similarity to recommend a movie based on the user's rated genre preferences.

Usage
-----
- Install dependencies: `pip install numpy` (or `pip install -r requirements.txt`)
- Run the script:

```bash
cd "projects/Simple Movie Recommender"
python simple_vector_similarity_engine.py
```

Input
-----
- You will be prompted to rate each genre on a scale from -10 to 10.

Notes
-----
- Implementation uses NumPy for vector math and cosine similarity.

- No expectation or commitment to extend or refactor the code at this time.

File
